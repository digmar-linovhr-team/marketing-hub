# Marketing Hub LinovHR

PWA untuk memantau Search Console, Google Ads, artikel kompetitor, serta kalender konten + SEO brief.

- Aplikasi: https://digmar-linovhr-team.github.io/marketing-hub/
- Backend: Google Apps Script di spreadsheet **Marketing Hub** (URL Web App di `config.js`)
- Data hanya bisa diakses setelah login dengan email kantor + PIN.

Saat mengubah file, naikkan nilai `CACHE` di `sw.js` (mis. `mhub-v2`) agar pengguna mendapat versi terbaru.
